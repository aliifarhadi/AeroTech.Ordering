# S6 - Typed ancillary and non-flight product sale

## Goal and user-observable result

Seat, baggage, meal, lounge, hotel and transfer products can be accepted with exact beneficiaries/coverage/pricing and appropriate resource owner.

## Entry gate and mandatory reading

Prerequisites: S5. Read `../DOMAIN/02-COMMERCIAL-COMPOSITION.md`, `../API-CONTRACTS.md`, `../DOMAIN/08-OPERATIONS-IDEMPOTENCY-AND-RECOVERY.md`, `../GOVERNANCE/03-STAGE-GATES.md` and the command/invariant/scenario indexes. Before code, write `artifacts/stages/S6/PLAN.md` with the exact commands/invariants/tests/files/layers for THIS slice. It applies the frozen design, not a new design proposal.

## Required work

1. Implement source product and pricing preparation, typed validation and explicit source profile snapshots.
2. Add immutable new item/service/membership/price facts and incremental obligations.
3. Support included/complimentary treatment without artificial zero-price lines.
4. Use FlightFlow only for products with flight capacity; use supplier port for independent non-flight booking.
5. Support shared room/vehicle and through-baggage coverage portions without multiplying commercial value.
6. Declare dependency dispositions for subsequent cancellation/change.

## Physical layer changes

Domain: the pure invariants and owned records in the primary specification. Application: one canonical handler per listed command plus typed orchestration/ports. Providers: wire ACL or isolated simulator only. Persistence: explicit owned mappings, indexes and enlisted stores. Synchronizer: extend the single OrderProjector. Query: local read projection only. RestApi/Consumers: translate/authenticate then dispatch; no second workflow. ServiceHost: explicit profile composition only.

## Idempotency, concurrency, Unknown and recovery

Follow DOMAIN/08 verbatim for external effects: receipt lookup precedes new eligibility; retain exact effect/profile/request; no external call inside SQL; lease/fence is not a commercial claim; late evidence is retained; authoritative absence needs proof. New local effects use SQL uniqueness and commit-result read-back. Distinguish cancellation of the HTTP wait from cancellation of a business operation.

Every new external mutation needs crash cases before intent commit, after intent commit, after dispatch, after owner commit/response loss, before local outcome commit and after local commit/response loss. D0 is inspection only and B0 applies these to generic infrastructure test messages, not invented sales.
