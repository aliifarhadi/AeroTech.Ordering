# S9 - Refund decision, commercial pivot and payout recovery

## Goal and user-observable result

The Order records a priced refund once, reserves valid payout authority and shows payout pending/confirmed independently.

## Required work

1. Implement immutable historical refund preparation and explicit acceptance.
2. Validate source pricing scope, direct reversal ceilings, tender refund ceiling and control/consumption.
3. Acquire refund authority before commercial/documentary pivot; reference scope disposition per choreography.
4. Commit accepted credit/penalty and refund disposition once, then execute payout as recoverable owner effect.
5. Distinguish RefundAuthorized from RefundConfirmed; preserve outstanding liability after payout failure.

## Persistence, transaction and read-model boundary
